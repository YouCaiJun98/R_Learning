## 词云图
* 这节课主要用了两个包，`jieba`和`wordcloud2`
    * `jieba`主要用于中文词语分词，这个包在很多编程语言里都有！比如`Python`里就有！它的底层是`C++`，把接口打包之后，就可以在其他编程语言中调用了！
    * 什么是 **“分词”** ？在英文中，词与词之间是空格连接的，所以很好划分；中文中，需要把不同的汉字进行组合，形成有意义的词组，这个过程就叫分词。
    * `jieba`在 4.5+ 版本的 `R` 中没有现成的安装包，需要自己本地编译安装（我们之前学过！见系列一！），代码如下：
        ```R
        library(devtools)
        install_github("qinwf/jiebaRD")
        install_github("qinwf/jiebaR")
        ```

* 介绍了`gsub()`函数，它的作用是全局替换文本里的内容（查找并替换），最常用在数据清洗、删数字、删符号。常见用法如下：
    ```R
    gsub(要找的内容, 替换成什么, 在哪里找)
    ```
    举例：
    ```R
    # 删除所有数字（把数字替换成空）
    tianmao$description <- gsub("[0-9]", "", tianmao$description)
    ```
    上面`[0-9]`表示所有数字，`""`表示空（删掉）。
    * 在课程的例子里，讲了一个正则表达式，其中，`'\\d'`表示匹配所有数字（0-9）。具体来说，`\d`表示数字（前面的`\`表示转义符，记得吗？）在这里，需要双重转义，即写成`'\\d'`。
* 介绍了`sort()`函数，它的作用是对向量（数字、字符）进行排序，返回排好序的新向量。基本语法如下：
    ```R
    sort(x, decreasing = FALSE, na.last = TRUE)
    ```
    其中，
    * `x`表示向量（数字、字符串）；
    * `decreasing=FALSE`表示默认升序（从小到大排序）；反之则是降序，从大到小排序；
    * `na.last=TRUE`表示 NA 放在最后。
