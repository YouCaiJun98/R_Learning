* 气泡图和散点图还是很像的，都是横纵坐标各表示一个变量。区别在于，气泡图中点的大小可以表示变量的大小。当数据量较小时才容易看得清楚，所以气泡图一般适用于数据量比较少的情况。

## 绘制气泡图
* 使用`symbols()`函数绘制气泡图。这个函数专门用来画带大小、带形状的符号图。本质上说，这个函数是在坐标点 (x, y) 上画自定义大小、形状的符号。函数的基本用法如下：
    ```R
    symbols(
        x = 横坐标,
        y = 纵坐标,
        circles = 气泡大小变量,  # 圆的半径
        inches = 0.3,           # 控制气泡最大尺寸（防止太大）
        bg = 填充色,            # 背景色
        fg = "black",           # 边框色
        main = "标题"
    )
    ```
* 介绍了`nrow()`这个函数，它的作用是返回数据框 / 矩阵的行数。
* 介绍了`dplyr`这个包里的`case_when`函数，来取代base `R`中的`ifelse`函数。这个函数是多条件判断函数，用来根据多个条件给变量赋值（如果 A → 赋值 1, 如果 B → 赋值 2, ...）。用法示例如下：
    ```R
    case_when(
        条件1 ~ 结果1,
        条件2 ~ 结果2,
        条件3 ~ 结果3,
        TRUE ~ 其他情况  # 可选
    )
    ```
