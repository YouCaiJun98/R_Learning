## 绘制直方图
* base `R`的局限性：绘制直方图时，横坐标需要是一个连续型变量，不能对分类变量绘制。
* 使用`hist()`函数画直方图，展示数据的分布形状、频率 / 密度。它的绘制逻辑是，把数据分成若干组区间，用柱子高度表示：每个区间里有多少个数据。基本用法如下：
    ```R
    hist(x, 
        main = "标题", 
        xlab = "X轴标签", 
        col = "颜色", 
        prob = TRUE)  # prob=TRUE 纵轴变密度（方便叠加核密度曲线）
    ```
* `hist()`函数是有返回值的，返回结果内包含每个组的边界、频数的大小、每个分组单元的概率密度。
* 介绍了一个`seq()`函数，它的作用是生成一串有规律的数字序列（等差数列）。使用示例如下：
    ```R
    seq(1, 10)          # 从1到10，默认步长1
    seq(1, 10, by=2)    # 从1到10，步长2 → 1,3,5,7,9
    seq(1, 10, length.out=5)  # 均分5个点
    ``` 

## 绘制核密度曲线
* 简单提到了几个核密度曲线的估计方法。
* 提到了一个“带宽”参数，带宽越小，曲线越不平滑，反之曲线越平滑。
* 用到了`density()`函数，它是专门用来计算并画出核密度曲线（经验概率密度 PDF）的函数。作用是，输入一组数据（如收益率、股价），输出一条平滑的概率密度曲线，用来看数据的分布形状（是否对称、峰值在哪、是否正态）。基本用法如下：
    ```R
    # 计算密度
    d <- density(数据)

    # 画出密度曲线
    plot(d)
    ```
* 又使用了`rnorm()`生成服从正态分布的数据（我们学过这个！）。

## 补充：核密度曲线与概率密度函数
* **核密度曲线**（Kernel Density Estimate, KDE）本质上就是对**概率密度函数**（PDF, Probability Density Function）的**非参数估计**。可以这么理解：
    * 它是样本数据真实 PDF 的“平滑近似版”；
    * 不是理论上的精确 PDF（比如正态分布的 PDF 是公式化的），而是从数据里 “算出来” 的、贴合样本分布的平滑曲线。
* 更明确地说，两者的关系为：
    * 理论 PDF 是随机变量的概率密度函数，是**数学公式**。它完全由分布参数决定，和样本无关，是理论上的 “理想分布”；
    * 核密度曲线（KDE）是用核函数对样本数据做平滑，得到的经验 PDF 估计。它完全由样本数据驱动，不假设分布形式，是对真实分布的 “数据驱动拟合”
* 那么，直方图和核密度曲线又有什么关系呢？
    * 直方图是离散化的 PDF 近似（用柱子高度表示区间内的概率密度）；
    * 核密度曲线是连续化、平滑化的直方图，本质就是把直方图的 “柱子” 连成了一条光滑的 PDF 曲线；
    * 两者的核心目标完全一致：展示随机变量在不同取值下的概率密度，也就是 “数据在哪个区间出现的概率更高”。
* 最后（其实一开始就该抛出来这个问题），什么又是**概率密度函数**呢？
    * （科普中国官方定义）概率密度函数（probabilitydensity function，简称PDF）是一个描述连续型随机变量的输出值在其定义域内某个确定的取值点附近可能性的非负可积函数，简称为密度函数。
    * **随机变量的取值落在某个区域之内的概率为概率密度函数在这个区域上的积分。**（你只要知道它的物理意义就可以！）当概率密度函数存在的时候，概率分布函数是概率密度函数的积分。
