## 查看内置配色方案
* `scales`和`tidyverse`的关系：`scales` 是 `ggplot2` / `tidyverse` 的官方配套包，专门负责颜色、刻度、格式化等绘图细节。这里用到的`viridis_pal()`、`brewer_pal()`、`hue_pal()`、`grey_pal()`全部都在 `scales` 包里，你加载 `tidyverse` 时，会自动加载 `scales`，所以直接用就行！
* `scales`/`ggplot2` 中自带一些调色板！例如，
    * Viridis系调色板有四种：
        ```R
        show_col(viridis_pal()(10))           # viridis
        show_col(viridis_pal(option="A")(10)) # magma
        show_col(viridis_pal(option="B")(10)) # inferno
        show_col(viridis_pal(option="C")(10)) # plasma
        ```
    我们以viridis为例，它的可视化结果如下：
    ![](https://raw.githubusercontent.com/YouCaiJun98/MyPicBed/main/imgs/20260423122118177.png)

    * ColorBrewer系调色板有三类：
        ```R
        # 定性调色板（Set1、Paired 等）
        show_col(brewer_pal(type="qual", palette="Set1")(9))

        # 顺序调色板（Blues、Greens）
        show_col(brewer_pal(type="seq", palette="Blues")(9))

        # 分歧调色板（RdBu、Spectral）
        show_col(brewer_pal(type="div", palette="RdBu")(9))
        ```
    我们以分歧色调色板RdBU为例，它的可视化结果如下：
    ![](https://raw.githubusercontent.com/YouCaiJun98/MyPicBed/main/imgs/20260423122308032.png)

    * 还有灰色系调色板：
        ```R
        show_col(grey_pal()(8))
        ```
    ![](https://raw.githubusercontent.com/YouCaiJun98/MyPicBed/main/imgs/20260423122416799.png)
